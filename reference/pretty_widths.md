# Use flextable::dim_pretty to fit column widths

Use flextable::dim_pretty to fit column widths

## Usage

``` r
pretty_widths(
  x,
  min_width = 0.05,
  unit = c("in", "cm", "mm"),
  table_width = 6.5
)
```

## Arguments

- x:

  flextable

- min_width:

  minimum width of columns

- unit:

  Can be `in`, `cm`, or `mm`

- table_width:

  width of table

## Value

flextable::flextable
