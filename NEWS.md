# apa7 0.3.0

## Changes that can affect existing tables

These change the output of code that worked with apa7 0.2.0.

* `table_width` works the same way in every function that takes it (`apa_flextable()`, `apa_style()`, `apa_cor()`, `apa_chisq()`, and `pretty_widths()`): a proportion of the page width from 0 to 1, the name of a width (`"page"`, `"landscape"`, or `"column"`), or a named number (e.g., `c(landscape = .8)` or `c(cm = 10)`). Its default, `NULL`, is the new `table_width` setting of `apa7_defaults()` (1, the full width of the page, unless changed). This changes three functions:
  * `apa_cor()`: `table_width` was a width in inches.
  * `pretty_widths()`: `table_width` was a width in `unit`, with `NULL` for the page width.
  * `apa_style()`: `table_width` defaulted to 0 (only as wide as the contents); use `table_width = 0` for that.

  A number greater than 1 is still read as inches (or in `unit` in `pretty_widths()`), with a warning to write it with its unit (e.g., `c(inches = 5)`), and a table wider than its page fills the page. In `apa_cor()`, the table's width now matches `table_width`: before, the number column's adjustment made the table wider than requested (e.g., 6.71 rather than 6.5 inches), and very narrow tables could get a Variable column of negative width.
* The `accuracy` setting now changes the number of decimals in tables. Before, the default column formats kept the accuracy they had when apa7 was loaded, so `apa7_defaults(accuracy = .001)` did not change the decimals of most tables. Setting `column_formats` without `accuracy` in `apa7_defaults()` makes the formats' own accuracy the `accuracy` setting.
* `apa_parameters()` introduces the fixed and random effects of mixed models (`lme4`, `glmmTMB`, and `nlme`) with "Fixed effects" and "Random effects" heading rows, as `parameters::model_parameters()` does. Use `effect_headings = FALSE` to leave them out. The random-effects heading names the statistic of the *SD* rows (e.g., "Random effects (*SD*)"), and each cluster (grouping factor) gets a subheading with its terms indented below it, so cluster names are not repeated on every row. Correlations name their own statistic (e.g., "*r* (Constant, Days)"), and nested clusters are spelled out (e.g., "Classroom in School").
* `apa_cor()` passes its other arguments to `correlation::correlation()` rather than `psych::corTest()`. `adjust` is still accepted as `p_adjust`, and `use = "complete"` removes incomplete rows, each with a warning.
* Table notes are now single-spaced, even when the table is double-spaced. This applies to `apa_flextable(note = TRUE)`, `apa_cor()`, `apa_chisq()`, and footers styled by `apa_style()`. `line_spacing` now sets only the spacing of the header and body.

## New table functions

* New `apa_descriptives()` makes descriptive statistics tables ("Table 1"): *M* (*SD*) or *Mdn* (*IQR*) for continuous variables and *n* (%) for categorical variables, with a column for each group of `by` and for the whole sample, and optional tests of group differences. `apa_note()` says which statistics are shown and lists missing values.
* `apa_descriptives()` uses Fisher's exact test instead of the chi-square test for a categorical variable whose table has an expected count below 5, and the note names those variables (`categorical_test = "chisq"` or `"fisher"` chooses one test for all). New `missing = "row"` shows the missing values of each variable in a "Missing" row instead of the note, and `range = TRUE` adds a "Range" row (minimum and maximum) below each continuous variable.
* New `apa_reliability()` makes reliability and item analysis tables: for each item, *M*, *SD*, the corrected item–total correlation, and Cronbach's α if deleted, followed for each scale by the scale mean and *SD*, α with a confidence interval, McDonald's *ω*~total~, and the mean inter-item correlation. It handles several scales, reverse-keyed items, and items scored 0 or 1 (difficulty and KR-20), and `level = "scales"` gives one row per scale.
* `apa_descriptives()` selects `variables`, `by`, and `categorical`, and `apa_reliability()` selects the items in `scales` and `reverse`, with unquoted or quoted names or tidyselect helpers (e.g., `variables = c(age, starts_with("item")), by = group` or `scales = list(Anxiety = anx1:anx5), reverse = c(anx2, anx4)`).
* New `apa_means()`, `apa_contrasts()`, and `apa_slopes()` make tables of estimated marginal means, contrasts (e.g., pairwise comparisons after an ANOVA), and simple slopes (e.g., to probe a moderation effect) from `modelbased::estimate_means()`, `estimate_contrasts()`, and `estimate_slopes()`. They take a model (with the modelbased arguments, such as `by`, `contrast`, `trend`, and `p_adjust`) or the modelbased output. Other variables in `by` get heading rows, probabilities from logistic models have no leading zero, and `apa_note()` says what the values are, how the other predictors were held constant, on which scale the estimates are, which level was subtracted from which, and how *p*-values were adjusted for multiple comparisons. Moderator values set with a modelbased shortcut are named (e.g., `by = "x=[sd]"` gives "−1*SD* (12.23)", "*M* (14.23)", and "+1*SD* (16.23)", and `"x=[fivenum]"` gives the minimum, quartiles, median, and maximum), contrasts between such values (`contrast = "x=[sd]"`) are labeled by name (e.g., "+1*SD* − *M*"), and a numeric variable named in `by` without values (`by = "x"`) is set to its mean and 1 *SD* above and below it rather than to the 10 values that modelbased uses by default. `by`, `contrast` (in `apa_contrasts()`), and `trend` (in `apa_slopes()`) are named arguments, and their variable names can be quoted or unquoted (e.g., `apa_contrasts(fit, contrast = cyl, by = am)`). Models with variable names that are not syntactic (e.g., `` `Partner Status` ``), for which marginaleffects gives standard errors of 0 or `NA`, are refit with syntactic names, and the tables keep the original names.
* `apa_contrasts()` adds Cohen's *d* with its confidence interval for models of continuous outcomes with an identity link (e.g., `lm()` and `aov()`): each difference divided by the model's residual standard deviation, with an interval that accounts for the uncertainty in that standard deviation (as in `emmeans::eff_size()`). For mixed models, give the standard deviation with `sd`. `effect_size = FALSE` leaves *d* out, and `apa_note()` says how it was computed.
* The note of `apa_slopes()` gives the Johnson–Neyman intervals (Johnson & Neyman, 1936) when the slope depends on a single continuous moderator through a two-way interaction: the values of the moderator, within its observed range, at which the slope is significant. The boundaries are computed exactly from the coefficients and their covariance matrix, rather than from a grid of moderator values. `johnson_neyman = FALSE` leaves them out.
* New `apa_collinearity()` makes tables of collinearity diagnostics from `performance::check_collinearity()`: the variance inflation factor (*VIF*) of each predictor with its confidence interval, and tolerance (or the standard-error inflation factor and the tolerance interval). Terms with more than 1 *df* get generalized *VIF*s, models with several parts (e.g., zero-inflated models) get a heading for each part, and `flag = 10` (or 5) bolds large *VIF*s. `apa_note()` names the terms with generalized *VIF*s, explains the *VIF*s of interaction terms, and defines tolerance.
* New `apa_htest()` runs *t* tests (Welch's or Student's, two-group or one-sample), Wilcoxon rank-sum and signed-rank tests, correlation tests (Pearson, Spearman, or Kendall), and chi-square tests of independence on the variables in a data frame, and makes a table with one row per outcome (e.g., `apa_htest(d, mpg + hp ~ am)`). It shows group means and standard deviations (or medians) under group spanners, the test statistic, *df*, *p*, and an effect size with a two-sided confidence interval: Cohen's *d* or Hedges' *g*, the rank-biserial correlation, or Cramér's *V*, *φ*, or Cohen's *w*. Effect sizes are computed from the data, so they do not depend on where the function is called, and Cohen's *d* for Welch's test is exact rather than approximated from *t*. `apa_note()` says which tests were done, how *d* was standardized, and what the abbreviations stand for.
* `apa_htest()` runs paired *t* tests and Wilcoxon signed-rank tests of paired variables with `Pair()` in the formula (e.g., `apa_htest(d, Pair(pre, post) ~ 1)`, or several pairs joined with `+`). Paired *t* tests show *d*~av~ by default, which is comparable to *d* for independent groups; *d*~z~, *d*~rm~, and Hedges' *g* versions come from `effectsize::repeated_measures_d()`. New `pair_labels` argument sets the headings above each pair's descriptive statistics.
* `apa_htest()` accepts test results already computed: an `htest` object from `t.test()`, `wilcox.test()`, `cor.test()`, or `chisq.test()`, or a list of them. Effect sizes are computed from what the objects keep (exactly for one-sample and paired *t* tests and for chi-square tests of independence, and approximately for two-sample *t* tests), and `apa_note()` says how.
* New `apa_subgroups()` makes a table of a subgroup analysis of a meta-analysis fit with `metafor::rma()`: each subgroup's *k*, pooled estimate, confidence interval, *p*, and *I*^2^, followed by the overall estimate. By default, each subgroup has its own *&tau;*^2^ and the subgroups are compared with *Q*~between~; with `tau2 = "common"`, the estimates and the test (*Q*~M~, or *F* with the Knapp–Hartung adjustment) come from a meta-regression with the subgroup as a moderator. `apa_note()` describes the model and gives the test of subgroup differences.
* New `apa_publication_bias()` makes a table of tests and corrections for publication bias in meta-analyses fit with `metafor::rma()`: Egger's regression test with its limit estimate, Begg and Mazumdar's rank correlation test, trim and fill with the number of imputed studies and the adjusted estimate, and (optionally) the fail-safe *N*. Adjusted estimates are on the same scale as in `apa_parameters()`, and `apa_note()` gives the unadjusted pooled estimate and describes each method.

## New models

* `apa_anova()` makes *F* tables of the fixed effects of linear mixed models from `lme4::lmer()` or `lmerTest::lmer()`, and formats ANOVA tables from lmerTest's `anova()`. Tests come from lmerTest, with Kenward-Roger (default, as in `apa_parameters()`) or Satterthwaite (`ddf = "Satterthwaite"`) denominator degrees of freedom, and are Type III by default. The table shows *df*~effect~, *df*~error~, *F*, and *p*. Partial effect sizes, computed from *F* and its degrees of freedom, are shown only when requested (e.g., `effect_size = "eta"`). `apa_note()` gives the type of tests, the degrees-of-freedom method, and how the effect size was computed.
* `apa_parameters()` and `apa_performance()` support mixed models fit with `glmmTMB::glmmTMB()`. Fixed effects are tested with *z* tests, coefficients of log and logit links are exponentiated by default (e.g., *IRR* for negative binomial models), and random effects are shown as for `lme4` models. Zero-inflation and dispersion parts appear under their own headings ("Zero-inflation model", "Dispersion model"), and `apa_note()` gives their scale. glmmTMB models also work in lists of models and in `apa_performance_comparison()`.
* `apa_parameters()` and `apa_performance()` support linear mixed models fit with `nlme::lme()`. Fixed effects are tested with *t* tests using nlme's degrees of freedom, random effects are shown as for `lme4` models, and parameters of residual correlation structures (e.g., `corAR1()`) and variance functions (e.g., `varIdent()`) are shown below the residual *SD*. `apa_note()` names the structures and says how the degrees of freedom were computed. `lme` models also work in lists of models and in `apa_performance_comparison()`.
* `apa_performance()` makes fit-index tables for `lavaan` models (e.g., from `lavaan::cfa()` and `lavaan::sem()`): the model *&chi;*^2^ test, CFI, TLI, RMSEA with its 90% confidence interval, and SRMR (or any of these plus AIC and BIC). Models fit with robust estimators (e.g., MLR or WLSMV) show the scaled *&chi;*^2^ test and robust (or scaled) indices. `apa_note()` gives the sample size, the estimator, and how missing data were handled, and defines the abbreviations. Lists of lavaan models give one row per model.
* `apa_parameters()` makes parameter tables for `lavaan` models. Fully standardized estimates (*&beta;*) with their standard errors and *p*-values are shown by default (`standardize = FALSE` for unstandardized estimates), under headings for factor loadings (e.g., Visual → x1), regressions (e.g., Speed ← Visual), correlations (e.g., Visual ↔ Textual), and defined parameters such as indirect effects. Variances, intercepts, and thresholds can be added. Parameters fixed to set the scale are not tested, and `apa_note()` names them, along with the estimator, the standardization, and robust or bootstrap standard errors.
* `apa_parameters()` supports multiple-group `lavaan` models. The groups are shown side by side under column spanners (or stacked under group headings with `groups = "rows"`), and `apa_note()` gives each group's size and names the parameters constrained to be equal across groups.
* `apa_loadings()` and `apa_factor_cor()` accept `lavaan` models. The loading matrix shows the fully standardized loadings, sorted as for exploratory analyses, with loadings fixed at 0 left blank (cross-loadings are shown), and the factor correlation table shows the standardized latent correlations. `apa_note()` gives the sample size and the estimator.
* `apa_performance_comparison()` compares nested `lavaan` models (e.g., the configural, metric, and scalar models of a measurement invariance analysis), each with the one before it. Each row shows the model's fit and, under a "Change from previous model" spanner, the *&chi;*^2^ difference test from `lavaan::lavTestLRT()` (scaled for robust estimators) and the changes in CFI and RMSEA (or TLI and SRMR). `apa_note()` names the difference test.
* `apa_cor()` computes its correlations with `correlation::correlation()` (now imported) rather than `psych::corTest()`, so the table can show Spearman, Kendall, robust, partial, or multilevel correlations with the new `method`, `p_adjust`, and `partial` arguments, and other arguments are passed to `correlation::correlation()`. The defaults (Pearson correlations, pairwise deletion, and unadjusted *p*-values) give the same tables as before. Variable names with spaces work for every kind of correlation, because `apa_cor()` uses internal names while computing them. `apa_cor()` also accepts the output of `correlation::correlation()`. The note says what kind of correlations are shown and how the *p*-values were adjusted for multiple comparisons.
* `apa_parameters()` and `apa_performance()` support multinomial logistic regression models fit with `nnet::multinom()`. Each outcome category gets a heading row naming its comparison with the reference category (e.g., "Part time vs. Not working"), with its coefficients indented below it (or `category_headings = FALSE` for labels such as "Part time: Constant"). Exponentiated coefficients are odds ratios relative to the reference category, labeled *OR*, and `apa_note()` names the reference category. `apa_performance()` reports McFadden's pseudo-*R*^2^, and lists of multinomial models are compared with likelihood ratio tests.
* `apa_parameters()` and `apa_performance()` support zero-inflated and hurdle count models fit with `pscl::zeroinfl()` and `pscl::hurdle()`. The count model and the zero model appear under their own headings ("Count model", and "Zero-inflation model" or "Zero hurdle model"), and only the count model's coefficients are exponentiated (*IRR*). `apa_note()` names the count distribution, gives the negative binomial dispersion parameter, and says what the zero model's coefficients mean. Lists of these models are compared with likelihood ratio tests.
* `apa_parameters()` and `apa_performance()` support meta-analyses fit with `metafor::rma()`. For models without moderators, `apa_parameters()` shows each study's effect size, confidence interval, and percentage of the total weight, followed by the pooled estimate under a rule. The effect-size column is named by the measure (e.g., *g*, *r*, or *RR*); ratios are exponentiated, and Fisher's *z* values are converted back to correlations (`transform = FALSE` keeps the analysis scale). Meta-regressions get a coefficient table, with exponentiated coefficients for ratio measures. `apa_performance()` gives *k*, *Q*, *&tau;*^2^, *I*^2^ (and *&tau;*, *H*^2^, and confidence intervals), and, for meta-regressions, the test of the moderators and *R*^2^. `apa_note()` names the measure and the model (including the estimator of *&tau;*^2^ and the Knapp–Hartung adjustment) and gives the test of the pooled estimate, its prediction interval, and the test of heterogeneity. Multilevel meta-analyses fit with `metafor::rma.mv()` (random intercepts at one or more nested levels, e.g., effect sizes in studies) get the same tables, with each level's variance component (*&sigma;*^2^) and the multilevel *I*^2^ (Cheung, 2014). A new article describes the tables.
* `apa_parameters()` and `apa_performance()` support generalized additive models fit with `mgcv::gam()` and `mgcv::bam()`. The table has the parametric terms (coefficients, standard errors, and *t* or *z* tests) and the smooth terms (effective degrees of freedom and approximate *F* or *&chi;*^2^ tests) under their own headings (`terms = "parametric"` or `"smooth"` shows one kind). Smooth terms are labeled by type and variables (e.g., "s(Age)", "te(Longitude, Latitude)"), with a row for each level of a factor-`by` variable, and `apa_note()` names the method that estimated the smoothing parameters. `apa_performance()` gives the adjusted *R*^2^ and the deviance explained. Lists of GAMs are compared by *R*^2^ and *AIC*, without nested tests, which are not well defined for penalized smooths.

## Table notes and citations

* Articles cited in table notes (e.g., for trim and fill or the multilevel *I*^2^) can be resolved by citeproc and added to the reference list. apa7 comes with a BibTeX file of these references, and `apa7_write_bib()` copies it to a document's folder. With the new `citations` argument of `apa_note()` (or `options(apa7.citations = )`), citations are written as Pandoc citation keys (`"keys"`, e.g., `[@duvalTrimFillSimple2000]`) or as text (`"text"`, e.g., "(Duval & Tweedie, 2000)"). The default, `"auto"`, writes a key when a Quarto or R Markdown document is being rendered and its bibliography has that entry, and text otherwise, so listing the file in the document's `bibliography` is enough. A bibliography set for a whole Quarto project or folder (in `_quarto.yml` or `_metadata.yml`) is found, too. References cited in notes inside flextables (from `apa_flextable(note = TRUE)`, `apa_cor()`, and `apa_chisq()`) are added to the document's reference list: ftExtra formats such a note on its own, so apa7 adds the keys to the document's `nocite` field when the table is printed. The keys are those of Zotero's Better BibTeX extension. Notes cite the methods they name: Kenward–Roger and Satterthwaite degrees of freedom, Greenhouse–Geisser and Huynh–Feldt corrections, generalized *&eta;*^2^, Feldt's confidence interval for &alpha; and McDonald's *&omega;*~total~, the generalized *VIF*, paired-samples *d*, Holm and Benjamini–Hochberg adjustments, the DerSimonian–Laird estimator and Knapp–Hartung adjustment, the multilevel *I*^2^, publication-bias methods, the MLM and MLR estimators and scaled *&chi;*^2^ difference tests of `lavaan`, and pseudo-*R*^2^ (Tjur, Nagelkerke, McFadden, and the marginal *R*^2^ of mixed models), which notes of lists of models now define.

## Settings

* `apa7_defaults()` sets all of apa7's settings in one place: new `print` and `citations` arguments set the `apa7.print` and `apa7.citations` options. Its other simple settings (`accuracy`, `font_family`, `intercept_text`, `width_aware_padding`, and `page_width`) are now R options, too (`apa7.accuracy`, `apa7.font_family`, `apa7.intercept_text`, `apa7.width_aware_padding`, and `apa7.page_width`), so they can be set with `options()`, including in an `.Rprofile` file, before apa7 is loaded. `apa7_defaults()` checks its values before changing anything, and it returns the previous values of the settings it changed, which `do.call(apa7_defaults, old)` restores (before, it returned the settings' environment itself, which changed along with the settings). `apa7_defaults(reset = TRUE)` now restores the same *p*-value formatter that is used when apa7 is loaded.
* New `page_width` setting in `apa7_defaults()` sets the width of the text area that tables fill: a number in inches, or the name of a paper size, whose width less APA's 1-inch margins is used (e.g., `apa7_defaults(page_width = "a4")` for 6.27 inches). The paper sizes are those of Typst's `page` function (e.g., `"a4"`, `"a5"`, `"us-letter"`, `"us-legal"`). `apa_flextable()`, `apa_cor()`, and `pretty_widths()` use it in place of the fixed 6.5 inches (the width of letter-size paper with 1-inch margins, which is still the default).
* Tables can be made for landscape pages and for two-column documents without changing the page width. `table_width = "landscape"` fills the text area of a landscape page, `table_width = "column"` fills one column of a two-column page, and `table_width = "page"` (or `"portrait"`) fills a portrait page, in every table function. A named number gives a proportion of one of these widths (e.g., `c(landscape = .8)`) or a width in `inches`, `cm`, or `mm` (e.g., `c(cm = 10)`).
  * New `landscape_width` and `column_width` settings in `apa7_defaults()` give these widths in inches. By default, they follow `page_width`: the paper's height less 1-inch margins (9 inches for letter-size paper), and the width of a column in apaquarto's two-column journal mode (`documentmode: jou`), which has 0.75-inch margins and a gutter of 4% of the text width (3.36 inches for letter-size paper).
  * New `table_width` setting in `apa7_defaults()` sets the default width of tables (e.g., `apa7_defaults(table_width = "column")` in a two-column document). Proportions given to a table function are then proportions of that width.
  * New `apa7-width` chunk option (`apa7.width` in R Markdown) sets the width of the tables made in one code chunk, including tables printed automatically, without changing any other table (e.g., `#| apa7-width: landscape`, or `#| apa7-width: {landscape: .8}`). A `table_width` given to a function overrides it. A chunk with apaquarto's `apa-twocolumn: true`, which spans a table across both columns of a two-column page, makes the table as wide as the page.
  * When `page_width` and `table_width` are not set with `apa7_defaults()`, the document being rendered supplies them: its `papersize` (e.g., `papersize: a4`) sets the paper, and apaquarto's `documentmode` sets the margins (0.75 inches on each side in journal mode and 1.5 inches on the left in thesis mode). In journal mode (`documentmode: jou`), which sets the text in two columns, tables are as wide as a column unless a chunk or function asks for another width, and a table with `apa-twocolumn: true` spans both columns.
  * The Getting Started article has a new section on table widths.
* New `font_size` setting in `apa7_defaults()` (the `apa7.font_size` option) sets the font size of all tables and their notes (12 points by default). `apa_flextable()`, `apa_style()`, `apa_cor()`, and `apa_chisq()` use it unless `font_size` is given.
* New `line_spacing` setting in `apa7_defaults()` (the `apa7.line_spacing` option) sets the spacing of the headers and bodies of all tables (2, double spacing, by default; APA style also allows 1.5 or single spacing in tables). `apa_flextable()`, `apa_style()`, `apa_cor()`, and `apa_chisq()` use it unless `line_spacing` is given. Notes stay single-spaced.

## Other improvements and bug fixes

* New `random_scale` argument for mixed models in `apa_parameters()`: `"sd"` (default) for standard deviations and correlations, or `"variance"` for variances and covariances. `apa_note()` defines the symbols.
* `apa_flextable()` keeps the table width set by `table_width` when `pretty_widths = TRUE`. Before, `pretty_widths()` reset it to the full width, so in HTML a table could be stretched wider than its columns.
* Decimal-aligned columns in `apa_flextable()` tables are centered in HTML as well as in Word.
* `apa_performance()`, `apa_performance_comparison()`, and `apa_parameters()` with a list of models no longer pass on insight's warning about variable names quoted in backticks (e.g., `` `SAT-V` ``), which read well in tables and give the same results as other names. Other warnings are passed on as before.
* `apa_cor()` centers every summary column (e.g., *SD*, which was off-center when its values had different numbers of digits).
* `apa_cor()` lines up correlations on the decimal point when there are no star columns (`star_significant = FALSE` or `bold_significant = TRUE`), and lines up the summary columns (e.g., *M*, Skewness, and Kurtosis) on the decimal point.
* `apa_flextable()` no longer re-formats row labels that `apa_parameters()` (for `lme4` and `glmmTMB` models) and `apa_htest()` have already formatted. Before, random-effect labels such as "Subject: *r* (Constant, Days)" lost their spacing and commas in flextables.
* The documentation of `table_width` in `apa_flextable()`, `apa_style()`, and `apa_chisq()` now says that it is a proportion of the container's width (from 0 to 1), not a width in pixels. A `table_width` that is not a valid width now gives a clear error instead of flextable's "width is > 1".

# apa7 0.2.0 _2026-10-18_

* New `apa_anova()` makes APA-style ANOVA source tables for `aov` and `lm` models (Type 1 sums of squares, or Types 2 and 3 via `car::Anova()`), repeated-measures `aov` models with `Error()` strata, `afex` models, and tables from `stats::anova()` and `car::Anova()`. Effect sizes (partial, non-partial, or generalized *η*^2^, *ω*^2^, or *ε*^2^) and their two-sided confidence intervals come from `effectsize`.
* New `apa_note()` writes the text of a table note. For `apa_parameters()` tables of regression models (including lists of models and `lme4` models), it says which robust standard errors were used, how mixed-model degrees of freedom were approximated, and that ordinal thresholds are not tested, and it defines the standardized coefficient, exponentiated coefficient (e.g., *OR*), confidence interval, and *R*^2^ change columns. For `apa_loadings()` and `apa_factor_cor()` tables, it gives the extraction method and rotation, says that oblique loadings are pattern coefficients, and explains omitted and bolded loadings and the *h*^2^, *u*^2^, and Complexity columns. For `apa_anova()` tables, it gives the type of sums of squares, which effects have sphericity-corrected degrees of freedom (`afex` models), what the effect size and *MSE* stand for, and what stars or bold values mean. With apaquarto, use it as `#| apa-note: !expr apa7::apa_note(tbl)`. Without apaquarto, `apa_flextable(note = TRUE)` places the note below the table.
* `apa_parameters()` now returns the ANOVA table for `aov`, repeated-measures `aov`, and `afex` models. Before, `aov` models were treated as `lm` models and gave a coefficients table.
* `apa_loadings()` has been reworked:
  * It now returns an `apa7_tbl`, so it renders as a flextable in Quarto and R Markdown. It supports `psych::principal()` as well as `psych::fa()`, and output from `parameters::factor_analysis()` and `parameters::principal_components()` (including unrotated components from `stats::prcomp()`).
  * New `bold_max` argument bolds the largest loading in each row.
  * New `factor_names` argument relabels the factors.
  * New `variance` argument adds rows for the sum of squared loadings and the proportion and cumulative proportion of variance explained, with a rule above them.
  * New `communality`, `digits`, and `format_variable_names` arguments. `apa_flextable()` no longer reformats item text in the `Variable` column.
  * Small loadings are now blank strings rather than `NA`.
  * The unused `column_formats` argument has been removed.
* New `apa_factor_cor()` makes a table of factor correlations from obliquely rotated `psych::fa()`, `psych::principal()`, and `parameters::factor_analysis()` solutions.
* `column_format()` gains an `abbreviation` slot that says what a header stands for (e.g., `"standardized coefficient"` for &beta;). `apa_note()` defines every abbreviated header in a table from these slots, for any table type, so setting the slot in `column_formats` adds or changes a definition. The default column formats define common abbreviations (e.g., CI, *AIC*, *BIC*, RMSEA, effect sizes, and *R*^2^ variants), and `column_formats()` gains a `get_abbreviations` getter. New column formats `h2`, `u2`, and `Complexity` set the headers of those `apa_loadings()` columns.
* `apa_flextable()` gains a `note` argument: `TRUE` adds the note from `apa_note()` below the table, and a character string adds a custom note. The note does not affect column widths.
* `apa_flextable()` leaves alone any columns named in a `"no_format_columns"` attribute of the data, and draws a rule above the row named in a `"rule_above"` attribute.
